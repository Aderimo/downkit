# Changelog

The notes shown in the app (Settings → Patch notes) live in `src/lib/releaseNotes.ts`; this
file is the same history for GitHub.

## v0.4.0 — 2026-10-16

DownKit is back as one free, open-source (MIT) app. Everything that was paid is gone: no Pro,
no licences, no purchases, no account.

**One app**

- Download from YouTube, TikTok, Instagram, X and hundreds of sites: format and quality,
  playlists, section download, subtitles, SponsorBlock, speed limit, history.
- Convert page: format (video, audio, image), compress to a target size, social media sizes,
  batch jobs on many files.
- Open a downloaded video in the editor with one click.
- Clip editor, screen recording, instant replay and screenshots are all in the same window.

**New**

- Motion titles drawn by the [EffectCraft](https://github.com/storytold/effectcraft) engine:
  lower third, title card, logo reveal, kinetic type, social square, vertical story, 3D text
  orbit; Lottie (`.json`) animations too. Transparent, positioned like an image layer.
- Audio: bass / mid / treble equaliser, compressor and limiter, with before/after preview.
- New default theme "Calm" (low saturation, soft contrast) and an interface size setting
  (Normal / Large / Extra large).

**Changed**

- Bug reports open a pre-filled GitHub issue (or Discord); there is no support server.
- Update check uses GitHub Releases.
- Settings, downloaded tools, projects and autosave move over from ClipKit and DownKit 0.3
  automatically on first launch; `.clipkit` project files still open.

## v0.3.0 and earlier

The original DownKit downloader (v0.1–v0.3). Its history is in this repository's earlier
