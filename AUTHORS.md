## How to tell an original build

- Official releases are published only on the GitHub page above and built from this repository
  by [GitHub Actions](.github/workflows/release.yml).
- Every build carries its author's signature. The app shows it under **Settings → About**, and
  the program file itself contains the line
  `DownKit vX.Y.Z | original author: aderimo | (c) 2026 aderimo | MIT | https://github.com/Aderimo/downkit`
  (search the `.exe` for `original author`). The file properties (**Details** tab) list
  `© 2026 aderimo`.
- Updates are signed with a private key only the author holds; installed copies accept
  updates only from it.
